## Verification Gates

- Run the existing full offline suite plus regressions for all seven findings using real Lua 5.1.
- Multiwindow regression: retain distinct Bags, Bank and Guild entries, refresh each independently, and verify source slots/item IDs remain correct through interactions and cross-character searches.
- Sale regressions: changed/new items while confirmation is open; same-link count changes; protection changes between ticks; unchanged approved candidates still sell.
- Mover regressions: conflicting operations in both orders, preoccupied cursor, replaced/changed source and bank closure during transfer.
- Persistence regressions: section names with Unicode/delimiters, legacy strings, explicit empty lists and malformed cached alts exercised through counts, menus and age rendering.
